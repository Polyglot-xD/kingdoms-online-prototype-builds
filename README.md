# Kingdoms Online prototype builds

## Current verified Windows build

[Download Kingdoms Online v0.1.2 for Windows](https://github.com/Polyglot-xD/kingdoms-online-prototype-builds/releases/download/v0.1.2-windows/KingdomsOnline-Windows-x64-v0.1.2.zip)

This exact public ZIP passed the
[Windows host and two-launch persistence test](https://github.com/Polyglot-xD/kingdoms-online-prototype-builds/actions/runs/38481429370).

Extract the complete Windows archive before launching `KingdomsOnline.exe`.
A normal launch starts a local authoritative host suitable for single-player.
Multiplayer and dedicated-host launchers are included but remain experimental.
